# Lumina · 交互实验室

一个零依赖、支持手机和桌面的中文交互可视化网页。下载后直接打开 `index.html` 即可使用。

## 功能

- 拖动两条波的振幅、空间频率与初始相位差，实时查看合成波。
- 相长干涉、完全相消、不同空间频率三组预设。
- 暂停、继续、重置；键盘可操作滑块与按钮。
- 遵循系统减少动态效果偏好，切换后台标签时停止绘制。

## 数学模型

`y₁(x,t) = A₁ sin[2πk₁(x − 0.12t)]`

`y₂(x,t) = A₂ sin[2πk₂(x − 0.12t) + φ]`

`y(x,t) = y₁ + y₂`

横轴为归一化位置，空间频率 k 为单位长度内的周期数。两条波采用相同传播速度 0.12 单位/秒。这是无量纲演示，参数不代表特定介质的测量结果。同空间频率时，合成振幅为 `sqrt(A₁² + A₂² + 2A₁A₂ cos φ)`。

## GitHub Pages

在仓库的 **Settings → Pages → Build and deployment** 中，将 Source 设为 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 后保存。部署完成后，以 GitHub Pages 页面实际显示的地址为准。

当前所有者为 `l47320877-rgb`，仓库名为 `Lumina.github.io`，因此它属于项目站点；用户根站点的仓库名需要与用户名完全对应。

## 本地运行

直接用浏览器打开 `index.html`，或在文件所在目录运行 `python3 -m http.server 8000` 后访问 `http://localhost:8000`。无需安装依赖或构建。

## 掌心星河：手势粒子

打开 [particles.html](./particles.html)，或从波动实验室顶部入口进入。支持星河、爱心、球体、蝴蝶四种粒子图形。

- 点击“开启摄像头手势”，在浏览器弹窗中允许摄像头。移动手掌控制位置，拇指与食指捏合 / 分开控制聚拢与展开，双手距离控制大小。
- 不开启摄像头也能操作：鼠标移动跟随，按住聚拢；触屏按住拖动。可用控件改变大小、旋转速度和粒子数量。
- 摄像头画面仅在浏览器内处理，不录制、不上传；关闭摄像头、离开页面或切换后台后停止摄像头轨道。
- 识别依赖 MediaPipe Tasks Vision 0.10.21（jsDelivr CDN）及 Google 托管的 Hand Landmarker 模型。首次加载需要联网；模型或 CDN 不可达时仍可用鼠标 / 触屏。
- 建议使用最新 Chrome 或 Edge，通过 GitHub Pages 的 HTTPS 地址访问。摄像头被占用时关闭其他视频软件；卡顿时改用 900 粒子。
- 模型加载失败有可重试提示。系统开启“减少动态效果”时默认关闭自动旋转。

页面控件与渲染已进行浏览器检查；真实摄像头识别效果需在有摄像头的设备上验证。
