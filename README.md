# Lumina · 交互实验室

两个面向手机和桌面浏览器的中文交互实验：

- **波动合成实验室**：调整两条波的参数，观察叠加与干涉。
- **掌心星河：手势粒子**：用鼠标、触屏或摄像头手势控制粒子。

项目是静态网页，无需安装 npm 依赖，也无需构建。摄像头手势需要联网加载 MediaPipe 库和识别模型。

## 在线体验

未配置自定义域名时，本仓库的默认 GitHub Pages 地址为：

- [波动合成实验室](https://l47320877-rgb.github.io/Lumina.github.io/)
- [掌心星河：手势粒子](https://l47320877-rgb.github.io/Lumina.github.io/particles.html)

最终以仓库 **Settings → Pages → Visit site** 显示的地址为准。

GitHub 仓库页面用于查看源码，GitHub Pages 地址用于运行网页。当前仓库名为 `Lumina.github.io`，所有者为 `l47320877-rgb`，因此这是项目站点，默认访问路径包含 `/Lumina.github.io/`。用户根站点的仓库名应为 `l47320877-rgb.github.io`，本项目无需为发布而改名。

## 手机快速开始

1. 将上面的在线体验地址复制到手机浏览器。
2. 优先在独立浏览器中打开；应用内置浏览器无法调用摄像头时，使用菜单中的“在浏览器中打开”。
3. 在波动页拖动滑块，或进入粒子页按住画布拖动。
4. 手机屏幕较窄时，粒子页控制区位于画布下方，需要向下滚动。
5. 想体验手势时，再按照下一节开启摄像头。

可先尝试 Android Chrome 或 iPhone/iPad Safari。基础交互采用响应式布局；真实摄像头识别效果仍需按设备实测，不能保证所有浏览器和手机都能正常运行。

## 掌心星河：使用方法

### 不开摄像头

- 鼠标：在粒子画布内移动控制位置，按住聚拢，松开恢复展开。
- 触屏：在画布内按住并拖动，松开恢复展开。
- 控制区：切换星河、爱心、球体、蝴蝶图形，调整大小、旋转速度和粒子数量。
- 卡顿时，先将粒子数量调到 900。

### 开启摄像头手势

1. 使用上面的 HTTPS 在线地址打开粒子页。
2. 点击“开启摄像头手势”。
3. 在浏览器权限提示中允许摄像头；本页面不请求麦克风。
4. 保持页面在前台，等待状态文字显示“识别已就绪”。出现摄像头预览不代表模型已经加载完成。
5. 将手掌完整放入预览框：
   - 单手移动：控制粒子位置。
   - 拇指与食指捏合或分开：控制聚拢与展开。
   - 双手入镜：改由双手距离控制聚拢与展开。
6. 使用结束后点击“关闭摄像头”。

预览使用镜像显示。尽量保持光线充足，避免手掌被遮挡。

**暂停动画不会关闭摄像头。** 页面切到后台或离开时会停止摄像头轨道；返回页面后需要再次点击“开启摄像头手势”。

### 联网与隐私

摄像头开启后，页面会加载：

- jsDelivr 上的 MediaPipe Tasks Vision `0.10.21` JavaScript 与 WASM；
- Google 托管的 Hand Landmarker 模型。

需要能访问 `cdn.jsdelivr.net` 和 `storage.googleapis.com`。浏览器可能缓存资源，但后续访问仍可能需要联网，本项目不保证离线手势识别。

当前页面代码在浏览器内处理摄像头画面，不录制、不上传画面；加载第三方库和模型仍会产生网络请求。

CDN 或模型加载失败时，会关闭摄像头并显示提示，仍可使用鼠标或触屏操作。

## 发布到 GitHub Pages

本项目无需构建，可直接从 `main` 分支根目录发布。

1. 打开[本仓库](https://github.com/l47320877-rgb/Lumina.github.io)。
2. 确认 `main` 分支根目录有 `index.html` 和 `particles.html`。
3. 打开 **Settings → Pages**。
4. 在 **Build and deployment** 中设置 Source 为 **Deploy from a branch**，Branch 为 `main`，Folder 为 `/ (root)`。
5. 点击 **Save**。如果这些设置已经正确，无需重复修改。
6. 打开仓库 **Actions**，确认对应最新提交的 `pages build and deployment` 运行成功。
7. 返回 **Settings → Pages**，点击 **Visit site**。
8. 分别检查首页、粒子页和两个页面之间的导航链接。

发布可能需要几分钟，GitHub 提示更新最长可能需要约 10 分钟。以后将网页修改提交到发布分支后，会自动触发更新；不需要每次重新设置 Pages，也不需要创建 Release。

## 本地运行

### 方式一：只查看波动页

下载并解压仓库后，可直接用浏览器打开 `index.html`。

粒子页包含模块脚本，建议使用下面的本地服务，不要将双击 HTML 作为粒子页和摄像头功能的验收方式。

### 方式二：启动本地服务

先安装 Python 3，在包含两个 HTML 文件的目录打开终端，然后运行：

```bash
python3 -m http.server 8000
```

Windows 如果没有 `python3` 命令，可尝试：

```powershell
py -m http.server 8000
```

在运行服务的电脑上访问：

- [波动页](http://localhost:8000/)
- [粒子页](http://localhost:8000/particles.html)

保持终端开启；按 `Ctrl+C` 停止服务。这里的 Python 只负责提供静态文件，不是网页运行依赖。本地摄像头识别仍需要联网加载外部资源。

### 手机访问本地服务的区别

手机上的 `localhost` 指向手机自身，不是你的电脑。

同一局域网下，手机可尝试通过 `http://电脑的局域网IP:8000/` 查看基础交互，前提是网络和电脑防火墙允许连接。

但普通局域网 HTTP 通常不满足摄像头的安全上下文要求。手机摄像头测试优先使用 GitHub Pages 的 HTTPS 地址。

## 常见问题

| 现象 | 排查方法 |
|---|---|
| 网页显示源码或文件列表 | 确认打开的是 Pages 地址，而不是 GitHub 仓库地址。 |
| 访问出现 404 | 从 Settings → Pages 的 Visit site 进入；检查发布目录、部署结果及网址中的仓库路径。 |
| 首页正常，粒子页 404 | 检查 `particles.html` 是否已提交到发布目录，文件名大小写是否一致。 |
| 修改后还是旧页面 | 等最新部署成功后刷新；必要时强制刷新或用无痕窗口检查缓存。 |
| 无法调用摄像头 | 检查是否使用 HTTPS 或本机 localhost，并尝试在独立浏览器打开。 |
| 摄像头权限被拒绝 | 在浏览器网站权限和系统隐私设置中允许摄像头，然后重新尝试。 |
| 摄像头被占用 | 关闭视频会议、其他摄像头标签页或应用，再重试。 |
| 有预览但没有识别 | 等待“识别已就绪”；若模型加载失败，检查网络后再次开启。当前模型加载等待上限约 45 秒。 |
| 切回页面后手势失效 | 后台时摄像头已关闭，需要手动重新开启。 |
| 画面不动 | 检查是否暂停了动画；系统“减少动态效果”会使波动页初始暂停、粒子页默认关闭自动旋转。 |
| 手机卡顿或发热 | 降到 900 粒子、降低旋转速度，或关闭摄像头使用触屏。 |

## 波动合成实验室

可调整两条波的振幅、空间频率和初始相位差，并使用相长干涉、完全相消、不同空间频率三组预设。支持暂停、继续、重置，以及键盘操作滑块和按钮。切换到后台标签时停止绘制。

数学模型：

```text
y₁(x,t) = A₁ sin[2πk₁(x − 0.12t)]
y₂(x,t) = A₂ sin[2πk₂(x − 0.12t) + φ]
y(x,t) = y₁ + y₂
```

横轴为归一化位置，k 表示单位长度内的周期数；两条波传播速度均为 0.12 单位/秒。这是无量纲演示，参数不代表特定介质的测量结果。

同空间频率时，合成振幅为：

```text
sqrt(A₁² + A₂² + 2A₁A₂ cos φ)
```
